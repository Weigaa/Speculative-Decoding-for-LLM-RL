## Newly included technical studies

All seven are **serving-transfer evidence**, not demonstrated target-policy RL acceleration. Each card states the transfer conditions and original measurement scope.

- [FACT](../papers/fares2026fact.md) — Combines step-weighted backpropagation through predicted-feature drafts with confidence-based candidate allocation under matched per-depth tree budgets, measuring how training and execution costs affect accepted progress.
- [G-MTP](../papers/galgani2026gmtp.md) — Uses one recurrent four-layer draft head conditioned on target activations, direct cross-attention to target KV without a separate draft cache, and clustered vocabulary projection, with joint or two-stage distillation after target fine-tuning.
- [SpecSearch](../papers/yildirim2026specsearch.md) — Uses a hardware cost model and calibration to choose autoregressive versus speculative execution, draft length and precision, including a batch-dependent length map and a learned selector for static configurations on unseen GPUs.
- [SpecRelay](../papers/jain2026specrelay.md) — Pipelines fixed-budget draft trees across edge-cloud round trips, hedges over alternative continuation anchors and rejects stale requests before target execution, with a separate latency-aware local/cloud router.
- [Callo](../papers/ou2026callo.md) — Uses repositioned KV invalidated by context edits for target-model drafting while exact re-prefill streams replacement KV, then verifies against exact state, with load-aware admission and early stopping.
- [Session-local recency and restraint](../papers/vandenbosch2026sessiondraft.md) — Copies continuations from the most recent matching prompt/output n-gram and can abstain below a match-length floor, comparing this cheap rule against recency-weighted session memory and confidence gating.
- [Raptor](../papers/hu2026raptor.md) — Uses accepted progress, uncovered target probability at the rejection frontier and wasted deep nodes to adjust tree depth, width and node budget with smoothing, bounded updates and expansion recovery.

FACT separates combined drafter-training changes, fixed-budget tree allocation and host execution effects. G-MTP distinguishes supervised domain adaptation from RL and target-forward counts from wall-clock savings. SpecSearch separates full calibration with dynamic draft lengths from a learned static selector. SpecRelay separates its cloud verification pipeline from local-model routing, whose matched aggregate accuracy does not preserve the cloud target distribution. Callo separates speculative gains from KV streaming and measured testbed results from cluster simulation. Session-local drafting is a distinct follow-up to the offline-trained Olifant study, with a different title, identifier and contribution despite shared author and repository. Raptor's appendix identifies a terminal-block/EOS accounting issue that should be resolved before its throughput is transferred to rollout evaluation.
