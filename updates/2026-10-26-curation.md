## Material version change requiring manuscript reconciliation

[SpecRoll v1](https://arxiv.org/abs/2608.04962v1) and [SPARK v2](https://arxiv.org/abs/2608.04962v2) are **one study**, arXiv:2608.04962. The v2 title and author list differ. Its current method description uses a low-rank correction shared within each prompt group and updated after each verification round. It resets the correction at rollout start while retaining a learned feature projection across rollouts. It does not update the draft backbone during generation or add target forward passes.

The v2 revision is dated October 14, so it was available on the manuscript cutoff date. This is not a newly published post-cutoff paper. The original SpecRoll title, reviewed v1, citation key and BibTeX remain intact, with a separate [version review on the card](../papers/pham2026specroll.md). Historical numerical claims have not been overwritten. Before submission, the author should reconcile the name, the fast–slow-head description and Table 6 classification with the version actually discussed, and check numerical claims against that version's original baseline and configuration.
