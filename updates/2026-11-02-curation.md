| Addition | Evidence and mechanism | Taxonomy placement |

| [NgramRL](../papers/pandey2026ngramrl.md) | Direct GRPO rollout evidence. Recent per-prompt n-gram history supplies model-free drafts; outcome-conditioned CPU prefetch overlaps GPU verification. | [SpecMem](../papers/song2026specmem.md) | Serving-transfer evidence for live tool-call draft stores with write-back, user scoping and bounded eviction. Canonicalized greedy-call prefix scores are proxies, separate from external-loop wall time. Tool execution gating is contextual, not an additional core method. | Workload recurrence; historical proposals; memory/state. |
| [TableTune](../papers/malvankar2026tabletune.md) | Serving-transfer evidence for measured batch-to-draft-length tables and online acceptance correction. Comparisons are with other speculative configurations; profiles, graph switching and a genuine off path matter. | Scheduling/mode selection; parallel/load-aware drafting. |
| [MDraft](../papers/molodyk2026mdraft.md) | Fixed-verifier drafter distillation using several draft blocks and aggregated verifier targets. “On-policy” refers to drafter-generated prefixes. The paper measures acceptance, explicitly not wall-clock speedup or RL training. | Proposal maintenance; parallel/load-aware drafting. |
