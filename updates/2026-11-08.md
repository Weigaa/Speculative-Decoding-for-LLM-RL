# Literature update — November 8, 2026

All six arXiv query families and six matching DataCite families completed with a 14-day overlapping window. Primary-source metadata and full text were reviewed for included studies. The hosted November 2 job succeeded. No exhaustive native search of every publisher database is claimed.

## Added studies

- [HyFlash](../papers/ko2026hyflash.md) — serving transfer. Combines recent-context attention with fixed-size recurrent memory of target features in a shallow parallel drafter.
- [Parallel Reconsideration](../papers/le2026reconsideration.md) — serving transfer. Revises uncertain feature-level guesses in parallel and appends refined candidates to the draft tree.
- [RECAP](../papers/zhu2026recap.md) — serving transfer. Combines request-local contextual prediction memories with persistent token-level memory to build verified candidate trees.
- [Hybrid Spark](../papers/ranjan2026hybridspark.md) — serving transfer. Selects between neural and n-gram draft chains using calibrated acceptance and a load-dependent verification-slot price.
- [SpecOPD](../papers/liu2026specopd.md) — serving transfer. Packs independent drafter-generated branches at reference anchors for parallel target supervision, preserving branch-specific sparse or recurrent state.
- [SpecPilot](../papers/li2026specpilot.md) — serving transfer. Uses a measured cost model and automated optimization to improve hybrid-target tree verification, batching and verification execution.
- [FactorSpec](../papers/su2026factorspec.md) — serving transfer. Compiles finite-domain schema relations into feasible token masks and deterministic draft runs, with per-request verification widths and CPU/GPU overlap.
- [Uni-LaSpec](../papers/nie2026unilaspec.md) — serving transfer. Selects visual context from verifier attention and switches between tree and truncated-chain verification according to current load.
- [Teaching Diffusion to Speculate Left-to-Right](../papers/whalen2026teaching.md) — serving transfer. Trains parallel drafters using position weighting, first-error focal loss and a surrogate for accepted-prefix length.
- [FlexFloor](../papers/wei2026flexfloor.md) — supporting. Coordinates history-based prompt placement and elastic expert parallelism to release completed ranks while preserving expert availability.
- [FlashOffloading](../papers/wang2026flashoffloading.md) — supporting. Overlaps host KV transfers with computation using rolling prefill and hot decode caches.

FlexFloor was author supplied and is included as RL infrastructure. Its expert-parallel resource reclamation is not counted as token-level speculative decoding. FlashOffloading is likewise supporting KV infrastructure; MTP is enabled in all reported decode arms.
